# Back end

NestJS + TypeORM + PostgreSQL API for the Workshop Registration Service.

Setup, test accounts and the API overview are in the [root README](../README.md); design notes are in [DESIGN.md](../DESIGN.md).

```bash
npm run start:dev   # API on http://localhost:3000 (watch mode)
npm run seed        # tables, test accounts and sample workshops
npm run lint
npm test
```
